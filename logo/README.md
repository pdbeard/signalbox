# signalbox logo files

| File | What it is |
|------|------------|
| `signalbox-logo.svg` | The logo used in the main README: the open box seen from above, with the back rim line |
| `signalbox-logo-no-rim.svg` | The same logo without the rim line (alternative) |
| `tray-icon-ok.svg`, `tray-icon-overdue.svg`, `tray-icon-failed.svg` | Sources of the tray icons: the logo box with one tile that fills the opening, in the status colour. `python3 generate_icons.py` renders them to `signalbox/icons/green.png`, `yellow.png` and `red.png` |
| `previous-logo.svg`, `previous-logo-variant.svg` | The earlier logo (floating panes over a blue box), kept for reference |

The name uses JetBrains Mono; where it is not installed, the SVGs fall back to the system's monospace font.
